Welcome to the RDX Browser

This browser was written from scratch for RDX: it fetches pages over HTTP and HTTPS with RDX's own TCP/IP stack and its own TLS (no libraries), and lays out the HTML itself, styled by the page's CSS: flexbox, grid, floats, tables, positioning, colours and sizes. It shows pictures (PNG, JPEG, GIF), fills in and sends forms, and runs the page's JavaScript.

Note on https: connections are encrypted, and each site's certificate is checked against the authorities in /roots.pem, so the browser knows it is talking to the real site. The status bar names the authority that vouches for it. If a site cannot prove who it is, the browser stops and says why.

Sites to try

Most sites work over https, for example https://en.wikipedia.org/wiki/Operating_system or https://news.ycombinator.com/. These are made to be light:

  • info.cern.ch - the very first web site (1991)
  • FrogFind - a search engine made for old browsers
  • 68k.news - news headlines, simplified
  • example.com - the classic example page
  • neverssl.com - plain http on purpose

How to use it

  1. Click the address bar (or press Ctrl+L), type an address, press Enter.
  2. Click a link to follow it. < (or Backspace) goes back, R reloads.
  3. Scroll with the arrow keys, Page Up/Down, Space, Home and End, or click the scroll bar.

Local pages

Files on RDX open too: type a path such as /home.html. Write your own page with edit mypage.html and open it here.

From a terminal, browser --dump http://example.com/ prints a page as text.
