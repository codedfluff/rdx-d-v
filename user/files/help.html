What the browser understands

Pages
HTML and plain text, over http:// or from local files. Redirects are followed.
Text
Headings, paragraphs, line breaks, bold, code, preformatted text, quotes, rules.
Layout
The page's CSS: flexbox, grid, floats, tables with real columns, positioned boxes.
Pictures and forms
PNG, JPEG, GIF and SVG pictures; text fields, checkboxes, menus and buttons. Tab moves between fields.
Scripts
JavaScript runs: the page's scripts can change it, react to clicks and typing, use timers, fetch data. Not supported: modules, generators. A script that runs too long is stopped. Turn scripts off with: set BROWSER_NOJS=1
Security
https with TLS 1.3; every site's certificate is checked before anything is sent.
Characters
&entities; and UTF-8. The text console simplifies letters: café shows as cafe. Pages are drawn in real fonts: Liberation Sans, Serif and Mono (the widths of Arial, Times New Roman and Courier New).
  Not (yet): JavaScript modules,
  fonts that pages download (web fonts).
